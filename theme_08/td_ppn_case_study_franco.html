Le billet en un coup d’œil

Caractéristique Détail
Émetteur Banque TD
Capital 100$ (protégé à l’échéance)
Échéance 4 ans (29 janvier 2030)
Sous-jacent Indice TD gr. cap. can. div. 265 RA
Niveau initial de l’indice \(\text{RA}_0 = 5\,468{,}46\)
Rendement majoré 20% si \(R_{\text{RA}} \geq 0\)
Taux de participation 5% pour \(R_{\text{RA}}\) au-delà de 20%
Commission de vente 2%

Ce que l’investisseur reçoit à l’échéance :

\[100\$ + \text{Rendement variable (RV)}\]

où

\[\text{RV} = \begin{cases} 0 & \text{si } R_{\text{RA}} < 0 \\ 20\$ & \text{si } 0 \leq R_{\text{RA}} \leq 20\% \\ 20\$ + 5\% \times (R_{\text{RA}} - 20\%) \times 100\$ & \text{si } R_{\text{RA}} > 20\% \end{cases}\]

Question clé : Quelle est la juste valeur de ce billet ?

Décomposition du rendement variable

Le rendement variable se décompose en deux options :

1. Option d’achat numérique (binaire) — paie 20$ si \(\text{RA}_T \geq \text{RA}_0\) :

\[20\$ \times \mathbf{1}_{\{R_{\text{RA}} \geq 0\}} = 20\$ \times \mathbf{1}_{\{\text{RA}_T \geq \text{RA}_0\}}\]

2. Option d’achat standard — participation de 5% au-delà du rendement de 20% :

\[5\% \times \max(R_{\text{RA}} - 20\%,\; 0) \times 100\$ = \frac{100\$}{\text{RA}_0} \times 5\% \times \max(\text{RA}_T - 1{,}2 \times \text{RA}_0,\; 0)\]

Un call de prix d’exercice \(K = 1{,}2 \times \text{RA}_0 = 6\,562{,}15\), pondéré par \(5\% \times 100\$ / \text{RA}_0\).

\[\boxed{\text{Juste valeur} = \underbrace{e^{-rT} \times 100\$}_{\text{obligation zéro-coupon}} + \underbrace{20\$ \times e^{-rT} \times N(d_2)}_{\text{call numérique}} + \underbrace{\frac{5}{\text{RA}_0} \times C(\text{RA}_0,\, 1{,}2 \times \text{RA}_0)}_{\text{call standard pondéré}}}\]

L’indice RA : rendement total avec un prélèvement

Le sous-jacent n’est pas un indice boursier standard.

  • L’indice de rendement total (RT) réinvestit tous les dividendes
  • L’indice de rendement ajusté (RA) soustrait un prélèvement fixe de 265 points d’indice par an
  • Ce prélèvement (~4,85% p.a.) permet à l’émetteur d’afficher un «rendement majoré de 20%» — mais la majoration ne compense même pas le prélèvement (la marge de l’émetteur est toujours de 5%)

\[\text{RA}_t = \text{RT}_t - 265 \times t\]

Implications pour l’évaluation :

  • Le prélèvement est un flux de trésorerie connu et déterministe — comme un coupon continu prélevé sur l’indice
  • Il n’est pas proportionnel au niveau de l’indice (arithmétique, pas géométrique)
  • Il faut un cadre d’évaluation qui gère proprement les flux connus
  • Idée clé : le cadre du prix à terme prépayé (Thème 1) traite ce cas exactement

Prix à terme prépayé (rappel)

Le prix à terme prépayé \(F^P_{0,T}(S)\) est le prix aujourd’hui pour recevoir l’actif au temps \(T\), sans flux intermédiaires :

\[F^P_{0,T}(S) = S_0 - \text{VA}(\text{flux non reçus par le détenteur du dérivé})\]

Sous-jacent Prix à terme prépayé
Action sans dividende \(F^P = S_0\)
Dividendes discrets \(D_{t_i}\) \(F^P = S_0 - \sum_i D_{t_i}\, e^{-r t_i}\)
Rendement continu \(\delta\) \(F^P = S_0\, e^{-\delta T}\)
Indice RA (prélèvement de 265 pts/an) \(F^P = \text{RA}_0 - \text{VA(prélèvement)}\)

Le prélèvement de 265 points par an est une annuité continue :

\[\text{VA(prélèvement)} = \int_0^T 265\, e^{-rt}\, dt = 265 \times \frac{1 - e^{-rT}}{r}\]

Calcul de \(F^P\) pour l’indice RA

Avec \(\text{RA}_0 = 5\,468{,}46\), \(T = 4\) ans, \(r = 3\%\) :

Code 
import numpy as np

AR_0 = 5468.46
T, r, drag = 4.0, 0.03, 265.0

PV_drag = drag * (1 - np.exp(-r * T)) / r
FP_AR = AR_0 - PV_drag

print(f"VA(prélèvement) = 265 × (1 - e^(-0.03×4)) / 0.03 = {PV_drag:.2f}")
print(f"F^P(RA)         = {AR_0:.2f} - {PV_drag:.2f} = {FP_AR:.2f}")
print(f"Ratio           = F^P / RA_0 = {FP_AR/AR_0:.4f}  ({(1 - FP_AR/AR_0)*100:.1f}% de décote)")
VA(prélèvement) = 265 × (1 - e^(-0.03×4)) / 0.03 = 998.87
F^P(RA)         = 5468.46 - 998.87 = 4469.59
Ratio           = F^P / RA_0 = 0.8173  (18.3% de décote)

Le prélèvement détruit 18,3% de la valeur de l’indice en termes de valeur actualisée.

Même si l’indice RT reste stable, l’indice RA aura baissé d’environ 1 000 points à l’échéance. C’est pourquoi le «rendement majoré de 20%» n’est pas aussi généreux qu’il n’y paraît.

La formule de Black-Scholes généralisée

Du Thème 5, le Black-Scholes généralisé évalue un call européen à l’aide des prix à terme prépayés :

\[C = F^P_{0,T}(S) \cdot N(d_1) - F^P_{0,T}(K) \cdot N(d_2)\]

\[d_1 = \frac{\ln\!\left(\frac{F^P_{0,T}(S)}{F^P_{0,T}(K)}\right) + \tfrac{1}{2}\sigma^2 T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}\]

Pour notre billet (\(F^P_{0,T}(K) = K \cdot e^{-rT}\) puisque le prix d’exercice est un montant fixe) :

  • Call numérique (paie 20$ si \(\text{RA}_T \geq \text{RA}_0\)) : \[\text{Numérique} = 20\$ \times e^{-rT} \times N(d_2) \quad \text{avec } K = \text{RA}_0\]

  • Call standard (participation de 5% au-delà de 20%) : \[\text{Standard} = \frac{5}{\text{RA}_0} \times \Big[F^P(\text{RA}) \cdot N(d_1) - F^P(1{,}2 \times \text{RA}_0) \cdot N(d_2)\Big]\]

Volatilité : de quoi avons-nous besoin ?

Pour appliquer Black-Scholes, il nous faut \(\sigma\). Défi : l’indice RA a un historique court.

Deux approches :

1. Volatilité implicite du marché

  • Utiliser les options sur XIU (iShares S&P/TSX 60 ETF)
  • Le TSX 60 a une composition très similaire à l’indice de 20 titres
  • Extraire la vol implicite ATM à la plus longue échéance disponible

2. Variance historique + prime de risque

  • Reconstituer le portefeuille de 20 titres à partir des données des constituants
  • Calculer la variance réalisée sur 5 ans
  • Ajouter une prime de risque de variance (PRV = 0,015)
  • Prendre la racine carrée

Approche 1 : Volatilité implicite du marché

Source de données : Bourse de Montréal (options sur XIU.TO)

Évaluation du billet

Code 
from scipy.stats import norm

sigma = 0.1623  # Historique + PRV
AR_0, T, r, drag = 5468.46, 4.0, 0.03, 265.0
PV_drag = drag * (1 - np.exp(-r * T)) / r
FP_AR = AR_0 - PV_drag
pv_principal = 100 * np.exp(-r * T)

# Call numérique : 20$ si RA_T >= RA_0
K1 = AR_0
FP_K1 = K1 * np.exp(-r * T)
d1_dig = (np.log(FP_AR / FP_K1) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
d2_dig = d1_dig - sigma * np.sqrt(T)
digital = 20 * np.exp(-r * T) * norm.cdf(d2_dig)

# Call standard : participation 5%, exercice = 1.2 * RA_0
K2 = 1.2 * AR_0
FP_K2 = K2 * np.exp(-r * T)
d1_van = (np.log(FP_AR / FP_K2) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
d2_van = d1_van - sigma * np.sqrt(T)
call_val = FP_AR * norm.cdf(d1_van) - FP_K2 * norm.cdf(d2_van)
vanilla = 0.05 * (call_val / AR_0) * 100

fair_value = pv_principal + digital + vanilla

print(f"VA du capital (obligation zéro-coupon) :  {pv_principal:.2f}$")
print(f"Call numérique (20$ × 1_{{RA≥RA₀}}) :       {digital:.2f}$")
print(f"  d₂ = {d2_dig:.3f},  N(d₂) = {norm.cdf(d2_dig):.3f}  (prob. risque-neutre de rendement positif)")
print(f"Call standard (5% au-delà de 20%) :       {vanilla:.2f}$")
print(f"{'─'*47}")

sigmas = np.linspace(0.10, 0.30, 100)

Approximation par rendement en dividendes continu

Approximer le prélèvement par un rendement proportionnel continu : \(\delta \approx 265 / \text{RA}_0 = 4{,}85\%\).

Alors \(F^P_{\text{approx}} = \text{RA}_0 \times e^{-\delta T}\) et on utilise le BS standard avec rendement continu.

Code 
delta = drag / AR_0
FP_approx = AR_0 * np.exp(-delta * T)

d2_approx = (np.log(AR_0 / AR_0) + (r - delta - 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
digital_approx = 20 * np.exp(-r * T) * norm.cdf(d2_approx)

d1v_a = (np.log(AR_0 / (1.2*AR_0)) + (r - delta + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2v_a = d1v_a - sigma * np.sqrt(T)
cv_a = AR_0*np.exp(-delta*T)*norm.cdf(d1v_a) - 1.2*AR_0*np.exp(-r*T)*norm.cdf(d2v_a)
vanilla_approx = 0.05 * (cv_a / AR_0) * 100

fv_approx = pv_principal + digital_approx + vanilla_approx

print(f"δ = {delta:.4f} ({delta*100:.2f}%)")
print(f"F^P (rendement continu) : {FP_approx:.2f}   vs.   F^P (exact) : {FP_AR:.2f}   (écart : {FP_approx - FP_AR:.2f})")
print(f"Juste valeur (approx.) :  {fv_approx:.2f}$   vs.   Juste valeur (exacte) : {fair_value:.2f}$   (écart : {fv_approx - fair_value:.2f}$)")
δ = 0.0485 (4.85%)
F^P (rendement continu) : 4504.87   vs.   F^P (exact) : 4469.59   (écart : 35.28)
Juste valeur (approx.) :  95.06$   vs.   Juste valeur (exacte) : 94.89$   (écart : 0.17$)

Seulement 0,17$ d’écart sur un billet de 100$. L’approximation par rendement continu sous-estime légèrement le prélèvement (proportionnel au niveau, alors que le vrai prélèvement est fixe à 265 points).

Rendement espéré pour l’investisseur

On suppose que l’indice RT (avant prélèvement) a un rendement espéré \(\mu_{\text{RT}}\). Avec \(\delta = 265/\text{RA}_0 = 4{,}85\%\) :

\[\mu_{\text{RA}} = \mu_{\text{RT}} - \delta\]

Le gain espéré utilise les formules de BS avec \(\mu_{\text{RA}}\) remplaçant \(r\) (mesure physique \(\mathbb{P}\)) :

\[\mathbb{P}(\text{RA}_T \geq K) = N\!\left(\frac{(\mu_{\text{RA}} - \tfrac{1}{2}\sigma^2)T}{\sigma\sqrt{T}}\right), \qquad \mathbb{E}^{\mathbb{P}}[\max(\text{RA}_T - K, 0)] = \text{RA}_0\, e^{\mu_{\text{RA}} T}\, N(d_1^{\mathbb{P}}) - K\, N(d_2^{\mathbb{P}})\]

Code 
mu_TRs = [0.02, 0.04, 0.06]
sigma_P = 0.1623
delta_drag = drag / AR_0

print(f"Prélèvement en rendement continu : δ = {delta_drag*100:.2f}%\n")
print(f"{'μ_RT':>5}  {'μ_RA':>7}  {'P(R≥0)':>7}  {'E[num]':>7}  {'E[std]':>7}  {'E[gains]':>9}  {'E[rdt ann]':>10}")
print("─" * 68)

for mu_TR in mu_TRs:
    mu_AR = mu_TR - delta_drag
    d2_P = (mu_AR - 0.5 * sigma_P**2) * T / (sigma_P * np.sqrt(T))
    prob_positive = norm.cdf(d2_P)
    E_digital = 20 * prob_positive

    K_v = 1.2 * AR_0
    d1_P = (np.log(AR_0 / K_v) + (mu_AR + 0.5 * sigma_P**2) * T) / (sigma_P * np.sqrt(T))
    d2_Pv = d1_P - sigma_P * np.sqrt(T)
    E_call = AR_0 * np.exp(mu_AR * T) * norm.cdf(d1_P) - K_v * norm.cdf(d2_Pv)
    E_vanilla = 0.05 * (E_call / AR_0) * 100

    E_payoff = 100 + E_digital + E_vanilla
    ann_ret = (E_payoff / 100) ** (1/T) - 1
    print(f"{mu_TR:>5.0%}  {mu_AR:>+7.2%}  {prob_positive:>6.1%}  "
          f"${E_digital:>6.2f}  ${E_vanilla:>6.2f}  ${E_payoff:>8.2f}  {ann_ret:>9.2%}")

print(f"\nRendement sans risque : 100$ à r = 3% → {100*np.exp(r*T):.2f}$ (3,05% p.a.)")

sigma = 0.1623
AR_0, T, r, drag = 5468.46, 4.0, 0.03, 265.0
PV_drag = drag * (1 - np.exp(-r * T)) / r
FP_AR = AR_0 - PV_drag
pv_principal = 100 * np.exp(-r * T)
delta_drag = drag / AR_0

def expected_return_atm_call(alpha, mu_TR):
    """Rendement annualisé espéré pour un billet avec participation alpha dans un call ATM."""
    mu_AR = mu_TR - delta_drag
    K = AR_0
    d1_P = (np.log(AR_0 / K) + (mu_AR + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2_P = d1_P - sigma * np.sqrt(T)
    E_call = AR_0 * np.exp(mu_AR * T) * norm.cdf(d1_P) - K * norm.cdf(d2_P)
    E_payoff = 100 + alpha * (E_call / AR_0) * 100
    return (E_payoff / 100) ** (1/T) - 1

def expected_return_digital(boost, mu_TR):
    """Rendement annualisé espéré pour un billet numérique($boost) + 5% standard."""
    mu_AR = mu_TR - delta_drag
    # Numérique
    d2_P = (mu_AR - 0.5 * sigma**2) * T / (sigma * np.sqrt(T))
    E_dig = boost * norm.cdf(d2_P)
    # Standard
    K_v = (1 + boost / 100) * AR_0
    d1_P = (np.log(AR_0 / K_v) + (mu_AR + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2_Pv = d1_P - sigma * np.sqrt(T)
    E_call = AR_0 * np.exp(mu_AR * T) * norm.cdf(d1_P) - K_v * norm.cdf(d2_Pv)
    E_van = 0.05 * (E_call / AR_0) * 100
    E_payoff = 100 + E_dig + E_van
    return (E_payoff / 100) ** (1/T) - 1
