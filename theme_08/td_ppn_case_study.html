Decomposing the Variable Return

The variable return can be decomposed into two option payoffs:

1. Digital (binary) call option — pays $20 if \(\text{AR}_T \geq \text{AR}_0\):

\[\$20 \times \mathbf{1}_{\{R_{\text{AR}} \geq 0\}} = \$20 \times \mathbf{1}_{\{\text{AR}_T \geq \text{AR}_0\}}\]

2. Vanilla call option — 5% participation above 20% return:

\[5\% \times \max(R_{\text{AR}} - 20\%,\; 0) \times \$100 = \frac{\$100}{\text{AR}_0} \times 5\% \times \max(\text{AR}_T - 1.2 \times \text{AR}_0,\; 0)\]

A call with strike \(K = 1.2 \times \text{AR}_0 = 6{,}562.15\), scaled by \(5\% \times \$100 / \text{AR}_0\).

\[\boxed{\text{Fair value} = \underbrace{e^{-rT} \times \$100}_{\text{zero-coupon bond}} + \underbrace{\$20 \times e^{-rT} \times N(d_2)}_{\text{digital call}} + \underbrace{\frac{5}{AR_0} \times C(AR_0,\, 1.2 \times AR_0)}_{\text{scaled vanilla call}}}\]

The AR Index: Total Return with a Drag

The underlying is not a standard equity index.

  • The Total Return (TR) index reinvests all dividends
  • The Adjusted Return (AR) index subtracts a fixed 265 index points per year
  • This drag (~4.85% p.a.) enables the issuer to advertise a “boosted 20% return” — but the boost doesn’t even fully compensate for the drag (issuer margin is still 5%)

\[\text{AR}_t = \text{TR}_t - 265 \times t\]

Implications for pricing:

  • The drag is a known, deterministic cash flow — like a continuous coupon stripped from the index
  • It is not proportional to the index level (arithmetic, not geometric)
  • We need a pricing framework that handles known cash flows cleanly
  • Key insight: the prepaid forward price framework (Theme 1) handles this exactly

Prepaid Forward Prices (Review)

The prepaid forward \(F^P_{0,T}(S)\) is the price today of receiving the asset at time \(T\), with no intermediate cash flows:

\[F^P_{0,T}(S) = S_0 - \text{PV}(\text{cash flows not received by derivative holder})\]

Underlying Prepaid forward
Non-dividend stock \(F^P = S_0\)
Discrete dividends \(D_{t_i}\) \(F^P = S_0 - \sum_i D_{t_i}\, e^{-r t_i}\)
Continuous yield \(\delta\) \(F^P = S_0\, e^{-\delta T}\)
AR index (265 pts/yr drag) \(F^P = \text{AR}_0 - \text{PV(drag)}\)

The drag of 265 points per year is a continuous annuity:

\[\text{PV(drag)} = \int_0^T 265\, e^{-rt}\, dt = 265 \times \frac{1 - e^{-rT}}{r}\]

Deriving \(F^P\) for the AR Index

With \(\text{AR}_0 = 5{,}468.46\), \(T = 4\) years, \(r = 3\%\):

Code 
import numpy as np

AR_0 = 5468.46
T, r, drag = 4.0, 0.03, 265.0

PV_drag = drag * (1 - np.exp(-r * T)) / r
FP_AR = AR_0 - PV_drag

print(f"PV(drag) = 265 × (1 - e^(-0.03×4)) / 0.03 = {PV_drag:.2f}")
print(f"F^P(AR)  = {AR_0:.2f} - {PV_drag:.2f} = {FP_AR:.2f}")
print(f"Ratio    = F^P / AR_0 = {FP_AR/AR_0:.4f}  ({(1 - FP_AR/AR_0)*100:.1f}% haircut)")
PV(drag) = 265 × (1 - e^(-0.03×4)) / 0.03 = 998.87
F^P(AR)  = 5468.46 - 998.87 = 4469.59
Ratio    = F^P / AR_0 = 0.8173  (18.3% haircut)

The drag destroys 18.3% of the index value in present-value terms.

Even if the TR index goes nowhere, the AR index will have fallen by ~1,000 points by maturity. This is why the “boosted 20% return” is not as generous as it sounds.

The Generalized Black-Scholes Formula

From Theme 5, the generalized Black-Scholes prices a European call using prepaid forwards:

\[C = F^P_{0,T}(S) \cdot N(d_1) - F^P_{0,T}(K) \cdot N(d_2)\]

\[d_1 = \frac{\ln\!\left(\frac{F^P_{0,T}(S)}{F^P_{0,T}(K)}\right) + \tfrac{1}{2}\sigma^2 T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}\]

For our note (\(F^P_{0,T}(K) = K \cdot e^{-rT}\) since the strike is a fixed amount):

  • Digital call (pays \(\$20\) if \(\text{AR}_T \geq \text{AR}_0\)): \[\text{Digital} = \$20 \times e^{-rT} \times N(d_2) \quad \text{with } K = \text{AR}_0\]

  • Vanilla call (5% participation above 20%): \[\text{Vanilla} = \frac{5}{\text{AR}_0} \times \Big[F^P(\text{AR}) \cdot N(d_1) - F^P(1.2 \times \text{AR}_0) \cdot N(d_2)\Big]\]

Volatility: What Do We Need?

To apply Black-Scholes we need \(\sigma\). Challenge: The AR index has a short history.

Two approaches:

1. Market-implied volatility

  • Use options on XIU (iShares S&P/TSX 60 ETF)
  • TSX 60 has very similar composition to the 20-stock index
  • Extract ATM implied vol at longest available maturity

2. Historical + variance risk premium

  • Reconstruct the 20-stock portfolio from constituent data
  • Compute realized variance over 5 years
  • Add a variance risk premium (VRP = 0.015)
  • Take the square root

Pricing the Note

Code 
from scipy.stats import norm

sigma = 0.1623  # Historical + VRP
AR_0, T, r, drag = 5468.46, 4.0, 0.03, 265.0
PV_drag = drag * (1 - np.exp(-r * T)) / r
FP_AR = AR_0 - PV_drag
pv_principal = 100 * np.exp(-r * T)

# Digital call: $20 if AR_T >= AR_0
K1 = AR_0
FP_K1 = K1 * np.exp(-r * T)
d1_dig = (np.log(FP_AR / FP_K1) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
d2_dig = d1_dig - sigma * np.sqrt(T)
digital = 20 * np.exp(-r * T) * norm.cdf(d2_dig)

# Vanilla call: 5% participation, strike = 1.2 * AR_0
K2 = 1.2 * AR_0
FP_K2 = K2 * np.exp(-r * T)
d1_van = (np.log(FP_AR / FP_K2) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
d2_van = d1_van - sigma * np.sqrt(T)
call_val = FP_AR * norm.cdf(d1_van) - FP_K2 * norm.cdf(d2_van)
vanilla = 0.05 * (call_val / AR_0) * 100

fair_value = pv_principal + digital + vanilla

print(f"PV of principal (zero-coupon bond):  ${pv_principal:.2f}")
print(f"Digital call ($20 × 1_{{AR≥AR₀}}):     ${digital:.2f}")

print(f"Vanilla call (5% above 20%):         ${vanilla:.2f}")
print(f"{'─'*45}")

Continuous Dividend Yield Approximation

Approximate the drag as a continuous proportional yield: \(\delta \approx 265 / \text{AR}_0 = 4.85\%\).

Then \(F^P_{\text{approx}} = \text{AR}_0 \times e^{-\delta T}\) and we use standard BS with continuous yield.

Code 
delta = drag / AR_0
FP_approx = AR_0 * np.exp(-delta * T)

d2_approx = (np.log(AR_0 / AR_0) + (r - delta - 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
digital_approx = 20 * np.exp(-r * T) * norm.cdf(d2_approx)

d1v_a = (np.log(AR_0 / (1.2*AR_0)) + (r - delta + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
d2v_a = d1v_a - sigma * np.sqrt(T)
cv_a = AR_0*np.exp(-delta*T)*norm.cdf(d1v_a) - 1.2*AR_0*np.exp(-r*T)*norm.cdf(d2v_a)
vanilla_approx = 0.05 * (cv_a / AR_0) * 100

fv_approx = pv_principal + digital_approx + vanilla_approx

print(f"δ = {delta:.4f} ({delta*100:.2f}%)")
print(f"F^P (continuous yield): {FP_approx:.2f}   vs.   F^P (exact): {FP_AR:.2f}   (diff: {FP_approx - FP_AR:.2f})")

Expected Return to the Investor

Assume the TR index (before drag) has expected return \(\mu_{\text{TR}}\). With \(\delta = 265/\text{AR}_0 = 4.85\%\):

\[\mu_{\text{AR}} = \mu_{\text{TR}} - \delta\]

The expected payoff uses BS formulas with \(\mu_{\text{AR}}\) replacing \(r\) (physical measure \(\mathbb{P}\)):

\[\mathbb{P}(\text{AR}_T \geq K) = N\!\left(\frac{(\mu_{\text{AR}} - \tfrac{1}{2}\sigma^2)T}{\sigma\sqrt{T}}\right), \qquad \mathbb{E}^{\mathbb{P}}[\max(\text{AR}_T - K, 0)] = \text{AR}_0\, e^{\mu_{\text{AR}} T}\, N(d_1^{\mathbb{P}}) - K\, N(d_2^{\mathbb{P}})\]

Code 
mu_TRs = [0.02, 0.04, 0.06]
sigma_P = 0.1623
delta_drag = drag / AR_0

print(f"Drag as continuous yield: δ = {delta_drag*100:.2f}%\n")
print(f"{'μ_TR':>5}  {'μ_AR':>7}  {'P(R≥0)':>7}  {'E[dig]':>7}  {'E[van]':>7}  {'E[payoff]':>9}  {'E[ann ret]':>10}")
print("─" * 68)

for mu_TR in mu_TRs:
    mu_AR = mu_TR - delta_drag
    d2_P = (mu_AR - 0.5 * sigma_P**2) * T / (sigma_P * np.sqrt(T))
    prob_positive = norm.cdf(d2_P)
    E_digital = 20 * prob_positive

    K_v = 1.2 * AR_0
    d1_P = (np.log(AR_0 / K_v) + (mu_AR + 0.5 * sigma_P**2) * T) / (sigma_P * np.sqrt(T))
    d2_Pv = d1_P - sigma_P * np.sqrt(T)
    E_call = AR_0 * np.exp(mu_AR * T) * norm.cdf(d1_P) - K_v * norm.cdf(d2_Pv)
    E_vanilla = 0.05 * (E_call / AR_0) * 100

    E_payoff = 100 + E_digital + E_vanilla
    ann_ret = (E_payoff / 100) ** (1/T) - 1
    print(f"{mu_TR:>5.0%}  {mu_AR:>+7.2%}  {prob_positive:>6.1%}  "
          f"${E_digital:>6.2f}  ${E_vanilla:>6.2f}  ${E_payoff:>8.2f}  {ann_ret:>9.2%}")

print(f"\nRisk-free benchmark: $100 at r = 3% → ${100*np.exp(r*T):.2f} (3.05% p.a.)")

What If the Note Were Designed Differently?

Code 
from scipy.optimize import brentq

sigma = 0.1623
AR_0, T, r, drag = 5468.46, 4.0, 0.03, 265.0
PV_drag = drag * (1 - np.exp(-r * T)) / r
FP_AR = AR_0 - PV_drag
pv_principal = 100 * np.exp(-r * T)
delta_drag = drag / AR_0

def expected_return_atm_call(alpha, mu_TR):
    """Expected annualized return for a note with participation alpha in ATM call."""
    mu_AR = mu_TR - delta_drag
    K = AR_0
    d1_P = (np.log(AR_0 / K) + (mu_AR + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2_P = d1_P - sigma * np.sqrt(T)
    E_call = AR_0 * np.exp(mu_AR * T) * norm.cdf(d1_P) - K * norm.cdf(d2_P)
    E_payoff = 100 + alpha * (E_call / AR_0) * 100
    return (E_payoff / 100) ** (1/T) - 1

def expected_return_digital(boost, mu_TR):
    """Expected annualized return for a note with digital($boost) + 5% vanilla."""
    mu_AR = mu_TR - delta_drag
    # Digital
    d2_P = (mu_AR - 0.5 * sigma**2) * T / (sigma * np.sqrt(T))
    E_dig = boost * norm.cdf(d2_P)
    # Vanilla
    K_v = (1 + boost / 100) * AR_0
    d1_P = (np.log(AR_0 / K_v) + (mu_AR + 0.5 * sigma**2) * T) / (sigma * np.sqrt(T))
    d2_Pv = d1_P - sigma * np.sqrt(T)
    E_call = AR_0 * np.exp(mu_AR * T) * norm.cdf(d1_P) - K_v * norm.cdf(d2_Pv)
    E_van = 0.05 * (E_call / AR_0) * 100
    E_payoff = 100 + E_dig + E_van
    return (E_payoff / 100) ** (1/T) - 1

# --- Alternative 1: Simple ATM call, no digital ---
K_atm = AR_0
FP_K_atm = K_atm * np.exp(-r * T)
d1_atm = (np.log(FP_AR / FP_K_atm) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
d2_atm = d1_atm - sigma * np.sqrt(T)
C_atm = FP_AR * norm.cdf(d1_atm) - FP_K_atm * norm.cdf(d2_atm)
cost_100pct = C_atm / AR_0 * 100

print("ALTERNATIVE 1: No digital, just ATM call (K = AR₀), participation α")

# --- Alternative 2: Keep digital+vanilla structure, solve for boost ---
FP_K1 = AR_0 * np.exp(-r * T)
d1_d = (np.log(FP_AR / FP_K1) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
d2_d = d1_d - sigma * np.sqrt(T)
Nd2 = norm.cdf(d2_d)

def total_option_value(boost):
    digital = boost * np.exp(-r * T) * Nd2
    K_van = (1 + boost / 100) * AR_0
    FP_Kv = K_van * np.exp(-r * T)
    d1v = (np.log(FP_AR / FP_Kv) + 0.5 * sigma**2 * T) / (sigma * np.sqrt(T))
    d2v = d1v - sigma * np.sqrt(T)
    cv = FP_AR * norm.cdf(d1v) - FP_Kv * norm.cdf(d2v)
    vanilla = 0.05 * (cv / AR_0) * 100
    return digital + vanilla
